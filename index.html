Proton Picker

The right Proton build for every game, chosen at launch.

Steam normally applies one global Proton choice or forces you to edit a per-game setting. Proton Picker sits at the launch point, reads the app ID, and starts a pinned build, a strongly supported build, or the newest installed official Proton. It keeps working when a games drive disappears.

  • Stop hunting through Steam Play settings for every game.
  • Pin a build per game without creating Steam overrides.
  • Survive missing builds and unmounted game drives.
  • Remove stale per-game overrides with a backup and restore path.

GAME DEVELOPMENT · CI · SAVE SAFETY

ReleaseGuard

One release-readiness gate for game builds.

ReleaseGuard combines trusted game-authored scenarios with packaged-build review. Test interrupted save writes, verify recovery behavior, collect logs, enforce step-duration budgets, and fail CI on size growth or development leftovers — without a hosted service.

  • Test whether an interrupted save write corrupts progress.
  • Gate releases on save, stability, timing, and packaging checks.
  • Detect oversized builds, duplicates, and shipped dev files.
  • Run on Windows and Linux with Python 3.10+.

ABOUT BRLINKIN

Small suite. Shared rules.

Both tools follow the same principles: run locally, make the safe choice explicit, keep a fallback, and never hide a failure behind a green checkmark. They are alpha software, priced free with optional donations while they earn real-world testing.

Local first

No accounts or telemetry. Proton Picker only sends game app IDs to public compatibility reports; ReleaseGuard runs entirely on your machine or CI.

Honest limits

Recommendations are evidence-based starting points. Save checks need game-specific adapters. Neither tool claims to fix every crash, stutter, or controller issue.

Restorable changes

Steam config edits are backed up. Removed per-game overrides are recorded for uninstall. Build reviews never modify your game.
